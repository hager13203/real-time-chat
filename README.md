# Realtime Chatroom

A simple real-time chat application built with **Node.js**, **Express**, and **Socket.IO**.

## Features

- Join and leave chatroom
- Real-time message broadcasting
- Socket events for new users, exits, and messages
- Simple front-end interface

## Technologies Used

- Node.js
- Express
- Socket.IO
- HTML/CSS/JavaScript
